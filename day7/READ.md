# Day 7: Simple Password Validator

## Objective

The objective of this project is to develop a simple Password Validator using Python. The application checks whether a password satisfies basic security requirements such as minimum length, uppercase character, lowercase character, number, and special character. The project demonstrates fundamental Python programming concepts, including strings, conditions, loops, string methods, character checks, and input validation.

## Technologies Used

- Python
- String Module
- VS Code

## Validation Rules

1. Password must contain at least 8 characters.
2. Password must contain at least one uppercase character.
3. Password must contain at least one lowercase character.
4. Password must contain at least one number.
5. Password must contain at least one special character.

## Features

- Accepts a password from the user.
- Checks the minimum password length.
- Checks for uppercase characters.
- Checks for lowercase characters.
- Checks for numeric characters.
- Checks for special characters.
- Uses the string module for special character validation.
- Provides clear validation messages.
- Handles multiple validation errors.
- Does not display the actual password unnecessarily.
- Clearly identifies whether the password is valid or invalid.

## Generated Files

- `password_validator.py` – Contains the Python program that accepts a password and checks whether it satisfies all the required validation rules.
