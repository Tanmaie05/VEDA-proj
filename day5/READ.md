# 🎯 Number Guessing Game

## Task 5 - Python Programming Track

### Objective

The objective of this project is to develop a Number Guessing Game using Python and Flask. The application generates a random number and allows the user to continue guessing until the correct number is found. The project demonstrates loops, conditional statements, random number generation, user interaction, and input validation.

### Technologies Used

- Python
- Flask
- Random Module
- HTML
- CSS
- VS Code

### Features

- Generates a random number between 1 and 100.
- Accepts guesses from the user.
- Provides hints when the guess is too high or too low.
- Counts the number of attempts.
- Stops the game when the correct number is guessed.
- Handles invalid input.
- Validates guesses between 1 and 100.
- Provides a web-based guessing game using Flask.
- Includes a reset option for starting a new game.
- Includes a responsive and modern interface.

### Files

- `guessing_game.py` - Contains the original Python console guessing game.
- `app.py` - Contains the Flask application and game logic.
- `index.html` - Contains the webpage design, input field, buttons, hints, and result display.
- `README.md` - Provides project documentation.
