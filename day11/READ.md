# Day 11 - Word and Character Counter

## 📌 Project Overview

This project is a Python-based Word and Character Counter that accepts a paragraph from the user and calculates basic text statistics.

The program counts:

- Characters
- Words
- Sentences
- Spaces

It also handles empty input.

---

## 🎯 Objective

The objective of this project is to practice:

- Python string manipulation
- String methods
- Basic text processing
- Regular expressions
- User input handling
- Conditional statements
- Functions

---

## 🛠️ Technologies Used

- Python
- Python String Methods
- Regular Expressions

---

## ✨ Features

- Accepts a paragraph from the user
- Counts total characters
- Counts total words
- Counts total sentences
- Counts total spaces
- Handles empty input
- Displays statistics in a clear format
