# Day 12 - Palindrome Checker

## 📌 Project Overview

This project is a Flask-based Palindrome Checker developed using Python.

The application accepts a word or sentence and determines whether it reads the same forward and backward.

The input is normalized by converting it to lowercase and removing spaces.

---

## 🎯 Objective

To practice:

- String manipulation
- String slicing
- String comparison
- Case normalization
- Conditional statements
- Flask web development
- User input handling

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS

---

## ✨ Features

- Enter a word or sentence
- Convert input to lowercase
- Remove spaces
- Reverse the input
- Check palindrome status
- Display normalized text
- Display reversed text
- Handle empty input
- Run on localhost
