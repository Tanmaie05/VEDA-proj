# Day 6: Multiplication Table Generator

## Objective

The objective of this project is to develop a simple Multiplication Table Program using Python. The application accepts a number and a specified limit from the user and generates its multiplication table up to that limit. The project demonstrates fundamental Python programming concepts, including for loops, the range() function, arithmetic operations, user input handling, validation, and formatted output.

## Technologies Used

- Python
- VS Code

## Operations Supported

1. Accept a number from the user.
2. Accept the multiplication table limit.
3. Generate the multiplication table.
4. Display the results in a formatted manner.

## Features

- Accepts a number from the user.
- Allows the user to specify the table limit.
- Generates the multiplication table using a for loop.
- Uses the range() function to control the loop.
- Performs multiplication for each value in the specified range.
- Handles invalid input.
- Validates that the limit is greater than zero.
- Displays the multiplication table clearly.
- Can generate tables for different numbers and limits.

## Generated Files

- `multiplication_table.py` – Contains the Python program that accepts a number and limit from the user and generates the multiplication table using a for loop.
