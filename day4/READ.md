# 🎓 Student Grade Calculator

## Task 4 - Python Programming Track

### Objective

The objective of this project is to develop a Student Grade Calculator using Python and Flask. The application accepts marks for multiple subjects, calculates total marks and percentage, and assigns a grade based on predefined conditions.

### Technologies Used

- Python
- Flask
- HTML
- CSS
- VS Code

### Features

- Accepts marks for multiple subjects.
- Validates that marks are between 0 and 100.
- Calculates total marks.
- Calculates percentage.
- Assigns a grade based on percentage.
- Handles invalid input.
- Displays results clearly.
- Provides a web-based grade calculator using Flask.
- Includes a responsive and modern interface.

### Files

- `grade_calculator.py` - Python grade calculator program.
- `app.py` - Flask backend.
- `index.html` - Web interface.
- `README.md` - Project documentation.

### How to Run

Run the Python version:

```bash
python grade_calculator.py
