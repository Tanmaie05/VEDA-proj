📚 Handled Exceptions

Exception Example Purpose
ValueError Invalid number Handles invalid numeric input
ZeroDivisionError 10 ÷ 0 Prevents division by zero
KeyError Missing dictionary key Handles unavailable keys
IndexError Invalid list index Handles unavailable positions
TypeError Invalid data types Handles incompatible operations
FileNotFoundError Missing file Handles unavailable files
