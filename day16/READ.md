# Task 16 - Employee Salary Calculator

## Objective

Build an Employee Salary Calculator using Python and Flask that calculates gross salary, deductions and net salary based on configurable salary rules.

## Features

- Employee name and ID input
- Basic salary input
- HRA calculation
- DA calculation
- Special allowance calculation
- Gross salary calculation
- PF deduction
- Income tax calculation
- Professional tax calculation
- Total deductions
- Net salary calculation
- Input validation
- Configurable salary rules
- Flask localhost interface

## Technologies Used

- Python
- Flask
- HTML
- CSS

## Data Structure

Employee and salary information is represented using Python dictionaries.

Example:

```python
employee = {
    "id": "EMP001",
    "name": "Tanmaie",
    "basic_salary": 50000
}
