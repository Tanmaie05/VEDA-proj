# 🔢 Even and Odd Number Checker

## Task 3 - Python Programming Track

### Description

A simple program that accepts a number and determines whether it is even or odd.

### Objective

Practice conditional statements and the modulus operator in Python.

### Technology Used

- Python
- Flask
- HTML
- CSS

### Features

- Accepts an integer from the user
- Checks whether the number is even or odd
- Uses the `%` modulus operator
- Handles negative numbers
- Handles invalid input
- Provides a web interface using Flask

### Files

- `even_odd.py` - Python program
- `app.py` - Flask backend
- `index.html` - Web interface
- `README.md` - Project documentation

### How to Run the Python Program

```bash
python even_odd.py
